# Rename column names of data exported from an ODK Aggregate Server or from ODK Briefcase into more usable and human readable variable names.

Rename column names of data exported from an ODK Aggregate Server or
from ODK Briefcase into more usable and human readable variable names.

## Usage

``` r
renameODK(data, sep = c(".", "-"))
```

## Arguments

- data:

  Dataframe object of dataset exported from ODK Aggregate Server or from
  local ODK directory

- sep:

  Character value for separator used in variable names. Choices are "."
  or "-". Default is ".".

## Value

Data frame object with renamed variables
